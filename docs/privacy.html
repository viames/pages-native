Privacy

Pages Native runs locally and does not send document contents or usage telemetry to its developer. It uses fixed native Apple Events workers. No Accessibility driver or clipboard access is required.

Requested tool results may include document text, tables, filenames, local paths and preview images. Your MCP host or AI service receives those results under its own privacy policy. Native operation does not prevent the host from receiving requested document content.

AppleScript request data is briefly stored in a private temporary directory, then removed. Backups, exports and previews remain at the chosen destinations.

Optional allowed-root checks guard plugin file paths; they do not sandbox the Pages application. Native acceptance passed on one Mac with Pages 14.5; other versions remain unverified.
