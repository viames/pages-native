# Native capability boundary

The core native workflows below passed real acceptance tests on one Mac running Pages 14.5. Individual tool combinations and other Pages/macOS versions are not exhaustively certified. The installed Pages scripting dictionary is the implementation source; dictionary declarations alone were not treated as proof.

| Area | Implemented surface | Limits |
| --- | --- | --- |
| Documents | Status, diagnostics, compatibility evidence, list/open/create/save/close/inspect, facing pages | Explicit IDs; canonical-path verified opening; list/open/save/close return lightweight metadata, while inspect obtains page/section counts. Close requires a save/discard choice. No layout-mode conversion. |
| Templates | Built-in IDs; opaque custom `.pages` copies | Saved sources only; never save the prototype. Native template IDs can vary. |
| Rich text | Body/section/page/text item/shape read; literal/range edit preview/apply; font/size/color | Native character indices; Existing text edits guard text; formatting guards text and per-character font/size/color. New text inherits insertion formatting. No full-body rewrite for existing edits. |
| Structured search | Literal native body/section/page/text/shape search, displayed table cells and optional formulas; context, native text positions or cell references, pagination | At most 100 text targets, 2,000 cells and 100,000 text characters. API-visible collections only; overlapping scopes can duplicate results. Search revisions do not authorize edits. |
| Recipe library and history | Local save/read/list/delete/restore; archived definitions and deduplicated opaque models; structural comparisons and historical reuse | History starts with 0.5; older unavailable bytes cannot be recovered. 1,000 entries per recipe; no last-use values or upload. See [history](BATCH-AND-HISTORY.md). |
| Batch generation | Preflight all records, then generate 1–10 separate native outputs sequentially with per-item results | New paths only; stop on error by default, always stop on uncertain state. Not transactional; no automatic retries. See [batch](BATCH-AND-HISTORY.md). |
| Guided composition | Required/default/optional fields with exact occurrence counts and typed native cell bindings; literal tokens or native tags; preview/apply on a new opaque saved-prototype copy | Up to 100 fields/targets and 200 replacements; no mixed literal/tag mode or overlapping body/section/page targets. No source saves, overwrite or rollback. See [recipes](SEARCH-AND-TEMPLATES.md). |
| Placeholders | Native document collection; exact existing-tag preview/apply | Does not claim discovery of hidden/unexposed placeholders. Duplicate tags need counts. Pages 14.5 rejects script-tag changes. |
| Tables | Create/update/delete, cells/formulas/dates, compatible base formats, range styles, sort/merge, dimensions | 2,000 cells per request. Product creation cap 1,000 rows/100 columns, subject to Pages' own limits. Preview/apply checks exposed values, formulas and styles. Whole-table resize/delete/sort snapshots are limited to 2,000 cells. No chart-source introspection. |
| Objects | Create text/shape/image; list/update/delete existing exposed objects | Preview/apply for position/dimensions/locking as exposed; source-image bytes are fingerprinted. Guarded object mutations are limited to 200 exposed objects; nested group snapshots also bound text/cell counts. Existing rich text edits use the guarded text tool. No chart series/type/title/data creation. |
| Files | New-path opaque backup; native exports; PDF/PNG previews | No overwrites for copies/exports. Backups require saved state. No private `.pages` parsing. |

No Accessibility/System Events, simulated input, private file-format APIs, automatic cloud hosting or document-content telemetry. Comments, tracked changes, hyperlinks, headings/lists, paragraph styles, headers/footers and detailed page/section setup are not implemented.

Text, placeholder, formatting, table, cell, object and facing-page guards re-read relevant API-visible state immediately before mutations. Unexposed attributes, such as merge topology and private chart internals, cannot be guarded. A preview makes no changes; apply requires the identical request and revision. They do not make Apple Events transactional. Failed post-checks and timeouts can leave partial edits; inspect rather than retrying automatically. A timed-out bridge is quarantined and retains its cooperative lock. Merge cannot cross a header-column/body-column boundary in Pages; inspect the table's header counts before choosing a range.
