# Verification

## Native acceptance — 20 October 2026

**Version 0.5.0 passed on one Mac:** macOS 27.0.1 (Darwin 27.0.0), Pages 14.5, Node.js 24.19.0. The native harness performed **76 checks** against new synthetic `.pages` fixtures in a private temporary directory using the exact bundled runtime, whose code fingerprints were compared with the final packaged plugin. It held the cooperative lock for the whole suite and closed only its own document IDs. The exported PDFKit PNG previews of the report, composed model and typed table were inspected visually: the edited heading, expense table, calculated 265 EUR total and text item were present.

The checks cover native Automation and template discovery; document create/save/close/reopen; body, section, page and page-layout text targets; Unicode character boundaries; font/size preservation around edits; preview and stale-revision guards; existing placeholder discovery and guarded filling; table formulas, literal strings, currency, dimensions, sort, merge/unmerge and resize/delete; text item, shape and image creation and image geometry; facing pages; opaque custom prototypes and backups; and native PDF, TXT, RTF, DOCX and EPUB exports.

New native tests reject style-only formatting changes, style/value changes before cell writes, stale geometry and a stale resize that would discard newly changed cells. Direct native calls also reject missing or stale preconditions. Locked object/table changes require an explicit unlock. Compatibility diagnostics expose an installed scripting-dictionary fingerprint without certifying the host.

Direct JXA opening of native copies timed out even though the copies appeared in Pages. Opening now resolves a native file alias, sends one AppleScript open event without waiting for its result, then verifies a document with the exact canonical file path and explicit ID. Both prototype opening and save/close/reopen passed the final suite. Listing/opening/saving/closing no longer forces page or section counts; those belong to explicit inspection. An unconfirmed opening quarantines the bridge and is never retried automatically.

Two real Pages behaviors changed the implementation. Assigning a string to a range of characters broadcasts it to every character; Pages Native now edits individual native characters in reverse order and checks the resulting text. Pages 14.5 rejects writes to placeholder script tags (`-10000`) despite exposing the property in its scripting dictionary. The unsupported tag-write tool was removed; filling placeholders with existing tags uses the native AppleScript command. Pages also rejects merges that cross a header-column/body-column boundary.

Structured search passed native body, section, page, text-item, shape, formatted-cell and formula checks, including complete Unicode boundaries, pagination and no text mutation. Formula queries use Pages’ actual localized formula text. Guided composition passed required/default/optional field validation, exact repeated occurrences, stale recipe/source-byte rejection, body/text-item filling, native script-tag filling, closed-source preview, source hash preservation, heading-format preservation, native rendering and persisted reopen. Fixtures own their lifecycle; only known synthetic IDs are closed.

Typed native model cells passed numbers/currency/percent, date timestamps, explicit formulas, literal formula-like strings, numeric zero defaults and deliberate optional clearing. Tests verify table name/index/address identity, duplicate-binding rejection, body/tag-plus-cell composition, source-byte preservation, native PDF rendering and persisted reopen. Recipe save/list/read, version conflicts, reuse with different values, no last-use value persistence, changed-prototype rejection and guarded deletion passed. Native probes showed that checkbox format is Numbers-only and boolean cell setters return numeric 0/1; the plugin rejects both before writing instead of silently coercing.

This is **one-host acceptance**, not universal certification. Other Pages/macOS releases and existing-chart geometry on a user-supplied document remain unverified. The API does not expose chart series/type/title, complete paragraph styles, comments or tracked changes. Native Apple Events are not transactional; inspect a document after any partial-write error or timeout.

Recipe history passed saved prototype capture, definition/prototype comparison, retained deletion events, restoration as a new current revision and historical model reuse after the original changed. Native two-record batch previews created no outputs; invalid records and duplicate destinations failed before copying. Current-recipe updates invalidated stale batch previews, while a selected unchanged historical version remained usable. Two independent saved outputs reopened with the original V1 text, compatible currency format and calculated totals 265 and 115. The saved V2 source remained byte-identical. Batch close-on-success and explicit leave-open behavior passed. Portable failure injection additionally checks stop/continue, uncertain-state stopping and preservation of partial/user-modified outputs.

Font/size/color checks do not certify named paragraph style assignment or semantic style preservation during model filling. The public scripting API does not expose those named styles.

## Portable and package checks

**70 portable tests passed.** They cover serialization and lock ownership, timeout/open-pending quarantine, private request-file transport, opaque copies and symlink/path restrictions, Unicode text planning, stale revisions, style/geometry/source-image guards, placeholder duplicate guards, cell-format preflight, lightweight document metadata, compatibility report aggregation, strict schemas and MCP client behavior. The clean bundled stdio smoke initializes the server and discovers **36 tools** from a copied plugin without runtime `node_modules`. These tests do not control Pages and are reported separately from native acceptance.

The actual locally installed **0.5.0** cache passed an independent MCP stdio workflow: 36-tool discovery, environment/evidence comparison, native model creation with currency and a formula, two saved model/recipe generations, historical two-record batch generation, automatic closing of successful outputs, native PDF/PNG preview and saved reopen. The outputs retained V1 text and calculated totals **265 and 115** while the V2 source stayed byte-identical. History comparisons detected the changed model; restoring V1 created revision 3, pointing to the archived prototype. Last-use recipient values were absent from the stored definition. The installed preview was inspected visually. Installed runtime/native bytes match the packaged and accepted source; earlier cache versions were preserved for existing chats.

See the [actual one-configuration matrix](compatibility-matrix.json) and [repeatable compatibility procedure](COMPATIBILITY.md). Failed/interrupted runs were not treated as successful acceptance. Report fingerprints identify the exact bundled runtime, native workers and harness; they are checked against the final distributable before installation.

The MCPB and official MCP Registry metadata schemas, plugin skills, deterministic ZIP checksums and fresh public download are release checks. Record their actual results in the release notes; do not treat a successful upload or listing submission as cross-Mac compatibility evidence.
