Pages Native

Apple Pages, natively.

A free, open source Codex plugin and MCP server for creating and editing real .pages documents on your Mac.

Preview 0.1.0. Native acceptance passed on one Mac with Pages 14.5 and macOS 27.0.1. Compatibility on other versions remains unverified.

Download 0.1.0Source & documentation

Work in the original format

Pages Native uses Apple's scripting API to edit documents, text, existing tagged placeholders, tables, formulas, shapes and images. It can export PDF, RTF, EPUB, text and Word copies when requested. The working document remains in native Pages format.

Rich-text edits can be previewed and applied with a revision check. Opaque copies preserve custom templates. A native PDFKit preview helps inspect the finished page.

Requires macOS, Apple Pages, Node.js 22+ and Automation permission. It uses no Accessibility driver, clipboard automation, Word editing backend or private Pages file parser.

Install in Codex

codex plugin marketplace add viames/pages-native
codex plugin add pages-native@viames-pages

Start a new local Codex task and run the plugin's setup skill. Verification and limits explain what was tested on a real Mac.
