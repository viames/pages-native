# Apple Pages, natively

Call `pages_status` first; `pages_compatibility` compares the current environment with recorded evidence without certifying this Mac. Native acceptance is recorded only for the actual tested Pages/macOS configuration. If the tool reports missing Automation permission, the user grants the host access in macOS Privacy & Security > Automation. No Accessibility permission is needed.

List/open the intended document and use its explicit `document_id`. Read its layout, text target and native indices before editing. Body text exists only in word-processing documents. Page-layout documents use text items or shapes. Document-wide object and table indices are 1-based and can change after deletion/reflow; inspect again rather than reusing stale indices.

For existing rich text use `pages_edit_text`: preview first, inspect the result, then apply the **identical target and operations** with its `expected_revision`. Prefer literal replacements with an expected match count. Range positions use the native character list returned by `pages_read_text`; do not count JavaScript UTF-16 units or split an emoji/combining character. Native insertions inherit insertion formatting; the revision checks text, not concurrent style changes. Edits are not atomic and do not provide rollback.

Formatting, tables/cells, sorting, merges, table dimensions, objects and facing-page changes now default to `mode="preview"`. Review `before`, `requested` and `notices`, then send the identical request with `mode="apply"` and `expected_revision`. The native worker rechecks exposed state before writing. A changed value, style, geometry, source-image content or operation invalidates the revision. A preview performs no mutation; do not mistake it for a completed edit. Re-preview after a rejected revision; never automatically repeat a failed mutation.

Use `pages_format_text` for native font faces, point sizes and RGB colors; its guard covers text and per-character font/size/color, bounded to 10,000 characters. Bold/italic require the appropriate font face. Paragraph styles, headings, lists, hyperlinks, headers/footers, comments, tracked changes, full page setup and chart series editing are not exposed by this plugin; never simulate these with UI controls or a converted Word file. Built-in/custom templates preserve features already designed in Pages.

Use `pages_search` for literal structured discovery. Default scopes search body, text items, shapes and formatted cells; optional formulas, page/section scopes, explicit `text_targets` and `table_ranges` narrow the scan. Text results use native-character positions; cell results identify table/address only. Search revisions are informational: obtain a fresh edit preview before writing. Inspect totals/pagination and boundary exclusions. Scope overlap can duplicate hits. Restrict large scopes when the tool reports its target/cell/text budgets; do not claim hidden content was searched.

Use `pages_compose` to fill a NEW copy of a saved custom prototype from a reusable fields recipe. Review required/default values, skipped optional fields, exact occurrence counts and native target mappings in preview; apply identical fields/paths with its revision. Never save the source as a workaround for unsaved changes without user intent. Use either literal tokens or native placeholder tags in a recipe, not both; either can also bind native table cells. Cell bindings require an explicit table index, exact table name and single A1 address. Pass numbers, `{date:"ISO timestamp"}` and `{formula:"=..."}` with their types; strings remain literal. Numeric zero is a valid required value; Pages coerces booleans to numbers and rejects checkbox controls, so these are refused before writing. An optional explicit null clears a cell. Compatible native base formats are preserved, not every custom format detail. The result reports completed fields and remaining native placeholders. On `COMPOSITION_INCOMPLETE`, inspect the new copy; individual native edits may have partially applied. See [search and model recipes](../../docs/SEARCH-AND-TEMPLATES.md) for scopes, examples and limits.

Use `pages_recipes` to list/read current definitions and `pages_recipe` to preview/apply save/delete/restore. Never put last-use `value` entries into saved definitions. `pages_recipe_history` lists/reads/compares archived definitions and prototype fingerprints. Restore creates a new current version; deleting retains history. `pages_compose_recipe` and `pages_compose_batch` accept `version` for a committed historical model. A pre-0.5 definition may lack recoverable prototype bytes. Move the whole library, including hidden history; do not edit it with an older client. A changed current prototype requires deliberately updating the recipe; an explicit source override must have identical bytes. See [typed fields and recipes](../../docs/RECIPES.md).

For 1–10 new outputs use `pages_compose_batch`: preview all records and apply identical items/options with its revision. Check every result and count; batches are not transactions. Default stop-on-error can be changed explicitly, but uncertain native state always stops. Never retry failed outputs automatically. Only successful saved unmodified outputs are closed by default; sources and unrelated documents stay open. See [batch and history](../../docs/BATCH-AND-HISTORY.md) for examples, migration and recovery boundaries.

List templates and choose an exact native template ID. `pages_from_template` copies an opaque saved `.pages` prototype without saving or changing the source. For existing tagged placeholders, preview `pages_fill_placeholders`; exact duplicate tags require `expected_count`. The collection covers only placeholders exposed by the native document API. Pages 14.5 rejects changing a placeholder's script tag through the native API.

For tables use table-relative A1 ranges, at most 2,000 cells per call. Resizing/deleting a table and sorting require a whole-table snapshot with at most 2,000 cells. Strings remain literal; use `{formula:"=..."}` or `{date:"ISO timestamp"}` explicitly. Read back formulas, calculated values and formats; format verification does not validate business calculations. Shrinking tables, merging cells and deleting objects can remove data. Guards cover exposed native properties, not unexposed merge topology, styles or chart internals; they do not create transactions or automatic rollback.

Use the native PDF/PNG preview for visual checks. `.pages` remains the editing format; PDF/RTF/EPUB/plain-text/Word outputs are explicit exports only. Backups require a saved document and a new path; `save_first=true` deliberately saves current edits. Close requires an explicit save/discard choice. Native table merges cannot cross header-column/body-column boundaries.

On a native error or timeout, inspect the affected document before deciding a next action. Never automatically repeat a mutation. A timeout quarantines the bridge and retains its lock; restart/remove a stale lock only after verifying Pages is idle.
